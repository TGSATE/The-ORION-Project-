## Folders

| Folder | What's inside | Who it's for |
|---|---|---|
| `SUGGESTIONS_FOR_THE_PROJECT/` | **New (OR20).** Tools and news for the group's decisions, each with pros, cons and cost; business-plan checklist | The whole team, before the group meeting |
| `SUGGESTIONS_FOR_BETH_TOOLBOX/` | **New (OR20).** Free tools for Beth only; the fix for uploading the big folder | Beth |
| `HOW_TO_NAVIGATE_THE_COSMOS/` | Plain guides: state of the game, game summary, have vs need, production plan, how games get made, tutorials | Anyone new |
| `ORION_MEMBER_PACKETS/` | One packet per member (Beth, Brianna, Bobby, Lucien, Marek, Matthew, Mike, Ryan, Shakes, Triss) | Each member |
| `ghostwriter_app/` | The Ghost Writer in the Mirror app (a phone web app; passes its tests, not yet tried on a real phone) | Coders, testers |
| `site/` | The Friction Atlas: an interactive companion to the friction-and-language essay | Readers |
| `CLOUDFLARE_READY/` | Zipped, ready-to-upload copies of the sites (Friction Atlas, Ghost Writer app, Lodge House) | Whoever deploys |
| `RequestProject/` | The Lean files: game rules written so a computer can check them (one folder per round; OR20 is `RequestProject/OR20/`) | Coders, checkers |
| `orion/` | Raw materials per round and level: Doc snapshots, transcripts, pictures, X posts. **Private copies live here, so don't share them** | Aristotle and Beth |
| `review/` | Small scripts that check links and claims | Coders |
| `ROUNDS_1-14_ARCHIVE/` | Every readout from Rounds 1–14, unchanged | History |
| `ROUNDS_15-19_ARCHIVE/` | Readouts from R15 through R19·L3 | History |
| `NEEDS_REPAIR/` | Broken or locked links, each reported once | Beth |
| `POTTY_FILES/` | The 18+ shelf | Adults only |
| `.lake/` | Downloaded maths library (Mathlib). Don't touch | The computer |
