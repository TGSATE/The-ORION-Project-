How private-to-public copying works
Uploading creates a private, browser-local archive. Type profiles help select matching file names; you can refine that selection manually. Preparing a public package copies only checked files, and the checkbox confirmation is required. Small packages can be shared in a URL; larger packages should be shared using the downloaded JSON file. Anyone with either copy can read its contents.
