TradeWars 71

Cabinet 03 · 15D chase
Monster Tag
A multi-agent tag-and-chase game concept in 15-dimensional Monster space, using Monster primes as dimensions and movement rules inspired by the group structure.
Action  Multi-agent  15D
Inventory lists:   MONSTER_TAG_GAME.md  and a commit note. The catalog does not establish a playable build.
