Binary-shift bridge unavailable

The bridge is defined only for p = 2. Change p in the scalar parameter panel to enable the binary cyclic-shift correspondence.

Why these maps correspond. For p = 2, multiplying by 2 modulo 2d − 1 cyclically shifts the d-bit representation. The scalar residue space contains 2d − 1 states; the vector space contains 2d, including a distinct all-ones vector.

The one-state difference

Both 0…0 and 1…1 are fixed under cyclic shift. In the scalar model, 1…1 represents 2d − 1 ≡ 0, so it is identified with the zero residue rather than counted as a second state.
