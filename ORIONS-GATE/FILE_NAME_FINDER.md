# File name finder: what those long number-and-letter names mean 🔎

*Round 22, 7 October 2026. You asked (doc line 773): "I have like 25 documents that are just numbers and codes and I have no idea what any of them are… help walk me through what the actual name is."*

## The short answer

Each time I finish a round, the whole project is saved under a **long code** that looks like `b74edf64-55ae-422d-8904-ffcacc9a824a`. A download can carry that code instead of a real name. **The code is the round, not the document.** The first 8 characters are enough to tell them apart.

## Three ways to find a file's real name, fastest first

1. **Look at the first 8 characters of the code** and find them in **Table A**. That tells you which round it came from and which file to open first.
2. **Open the document and read its very first line.** Every file I write starts with a title, and **Table B** gives the title for every file. Find the title, and the real name is next to it.
3. **Rename it right away.** Save it with the name from Table A or B, for example `R21 ROUND_TWENTY_ONE_READOUT`. If you start each name with the round number (R21, R22…), your folder sorts itself in order.

**Tip for the 25 already sitting there:** you don't have to sort them all. Do step 2 on the newest ones only. Anything from before Round 19 is already summarised in later readouts, so you can leave those or delete them.

**Today's round (Round 22)** gets a new code that I can't see until the round is finished, so it isn't in Table A yet. Its start file is `ROUNDS_1-14_ARCHIVE/ROUND_TWENTY_TWO_READOUT.md`.
