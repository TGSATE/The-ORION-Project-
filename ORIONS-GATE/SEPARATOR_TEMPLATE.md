## 2. What each line means

| Line | Means | What Aristotle does |
|---|---|---|
| `OR17🌀…⏭️` | Where it came from (last round) | Reads it as history. Doesn't redo it |
| `OR18🌀…⏭️` + **NEW NEWS** | This round is open; news feeds and group grabs | Sorts it. **No second copies:** if a file already exists, the readout says "already filed: [file]" |
| `🌀…OR18.1` | **Level start:** the spiral session begins | Reads everything after it |
| "Any 🌀🧿🌀 still running" | Open threads carried in | Lists them first in the readout |
| `⏬⏬⏬` … `🆙🆙🆙` | **Your parking space** for finding your place | **Skipped.** Nothing in there is read as an instruction |
| `🌀…OR18.1🧿` + `ARI:RO🌀` | **Readout examination:** my readout pasted in, with your marks | Close examination: line-by-line answers to every mark |
| `🌀…⏭️OR18.2` | **What the next level will be** once this is sent | The readout says "Coming from 18.1 → porting to 18.2" |
| `🌀…⏭️OR19` | Round finished; the next round has started | Readout labelled as the round close |
| `💎💎💎💎💎💎💎💎💎` | Final audit, no further changes | Treated as locked |

## 3. The emoji audit: what we have, where it collides, what works better

**What's in use now:**

| Emoji | As a separator line | As a mark on a line |
|---|---|---|
| 🌀 | a row of 8 = separator | single 🌀 = "add this" |
| ⏭️ | "next starts here" | none |
| 🧿 | on a separator = examination section; inside the end line | on a line = "examine this closely" |
| 💎 | a row of 9 = final audit | single 💎 = locked |
| ☢️ | old stop line: nine in a row | emphasis or warning (🧐☢️) |
| ⏬ / 🆙 | parking block | none |
| 🤟 ❌ 🧐 🔥 🆘 😈 | none | yes · wrong · explain/check · urgent · stop and reread · Beth already grabbed it |
| 🐶🐲 🐗 👾 🎭 | none | speaker marks: Grok · Boardy · Mike/coders · Muse |

**Where they collide, and the fix (nothing new to learn):**
1. **☢️ means both "stop" and "pay attention".** Fix: **only a line that is exactly `☢️☢️☢️🧿☢️☢️☢️` (or the old nine ☢️), with nothing else on it, is the end.** ☢️ anywhere else is just emphasis. Put "Nothing left to see here" on the *next* line, not the same one. *(Checked in Lean.)*
2. **🌀 means both "separator" and "add this".** Fix: a separator is a **row** of 🌀 plus a round label (OR18.1). A single 🌀 at the end of a sentence is always "add this".
3. **⏭️ before or after the label.** Fix: **position doesn't matter.** ⏭️ anywhere on a separator means "next starts here". **OR18.2 (with a dot) = a level; OR19 (no dot) = a new round.**
4. **💎 means both "locked" and "final audit".** No real clash: one 💎 locks a line, a row of nine locks the whole round.
5. **🧿 shows up three ways.** No clash, because the end line is matched exactly.
6. **The template's `OR19.2` line had no ⏭️.** Read literally, that turns it into a level *start*. Fix: **put ⏭️ on it (`⏭️OR18.2`)** so it clearly means "next level". That's already in the skeleton above.

**Your softer ending: yes.** `☢️☢️☢️🧿☢️☢️☢️ / Nothing left to see here` is now **the** end line. The old nine-☢️ line still works, so old Docs read the same, but you never need it again.
