## 6. Computer checks (Lean: no unfinished proofs, no extra assumptions)

The new file `RequestProject/R15/Level7Checks.lean` builds cleanly, and the whole project still builds. It checks only the maths printed on the pictures:

- **#1489:** φ²³ = 28657·φ + 17711 is **true**. In general φⁿ⁺¹ = F(n+1)·φ + F(n), where F is the Fibonacci sequence, so 28657 and 17711 are Fibonacci numbers 23 and 22.
- **#1418:** with half-angles, cos(θ/2)|R⟩ + e^{iφ}·sin(θ/2)|L⟩ always has length 1, as a light state must. As printed, cos(θ2) read as cos(2θ) **fails**: at θ = 90°, φ = 0 the squared length comes out as 3/2. So the poster has a typo.
- **#1459 (Scroll of the True Name):** with A = 1 … Z = 26, **TRISTA adds up to 87, not 37**. The scroll's next line uses 8 + 7 = 15 for the Flame Number, which matches 87, so "37" is a typo. The scroll's letter list also leaves out the final A; the five letters it does list add up to 86.
- **#1480 (Geometry Camp):** the kernel of any linear map always contains zero, so "the kernel dies at zero" really is where it lives.
