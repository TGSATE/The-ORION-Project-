# Original image prompts from the R16·L6 inspiration shelf

The user shared an illustration by @LensScientific and admired @Divine_Emissary's post. I could read the posts and see their still images, but could not establish either account's availability for paid collaboration, game development, coding, or reuse permission from the posts. These are **new prompts for original assets**, not instructions to duplicate someone's image, claim their style as ours, or use their work in a game without permission. Generated output should be checked by a human for attribution and distinctiveness.

## 1. Stellar remnant classroom card
```text
Create an original two-panel educational game card for ORION's Guide to the Galaxy. Left: a small white dwarf in a binary system with a labeled transfer stream and a thermonuclear Type Ia outcome. Right: an aging massive star with a layered core, collapsing inward then ejecting its outer layers, labeled core collapse. Elegant midnight-blue and copper palette, restrained mathematical linework, large readable labels, clear arrows, no brand names, no imitation of an existing illustration. Below each panel leave space for one evidence link and one 'what we still don't know' note. No misleading claim that all exploding stars work the same way.
```
## 2. A cosmic-source gate (without pretending a metaphor is physics)
```text
Original ORION game environment: a library observatory with five gently glowing elemental lanterns and two doorways. One reads STORY / imaginative speculation; the other reads EVIDENCE / sources and measurements. Players can cross between them; the interface clearly says when a claim is a scientific observation, a proposed hypothesis, or a fictional world-building idea. Accessible high contrast, spacious UI labels, readable on a phone, no existing franchise characters or copied artwork.
```
## 3. Accessible texture/poetry card
```text
Create an original abstract cosmic garden card for a reflective writing game: translucent dew, prism-like pale ribbons and quiet charcoal ground. Make it contemplative, not a medical illustration. Add a plain text caption: 'This is an image for reflection, not an explanation of eye physiology.' Keep symbols invented, avoid replication of a specific social-media image, watermark, sacred iconography or living artist's signature.
```
