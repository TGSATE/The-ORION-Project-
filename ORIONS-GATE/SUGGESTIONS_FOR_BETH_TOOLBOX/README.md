## T-1. ⭐ The upload problem (2,400+ files): try this first

What's going on: browsers struggle to upload thousands of small files one by one. Uploads freeze, and folders can show
up **empty**. SeaDrive often shows "placeholder" files that only live online until they're downloaded, so copying from
it can copy **empty shells**. That's likely why "it moves the project over but doesn't put anything in it". It isn't
you. It's a known weak spot.

1. **Make one zip file first.** On the laptop, right-click the big folder → **Compress** (Mac) or **Send to → Compressed
   (zipped) folder** (Windows). Now it's one file, not 2,400.
   - If it came from SeaDrive: right-click the folder in SeaDrive and pick the option to keep it on the computer
     (download / "always keep") **before** zipping, so the files aren't empty.
2. Go to **drive.google.com** → **+ New → File upload** → pick the **.zip**. Leave the tab open until it says done.
3. Right-click the zip → **Share** → **Anyone with the link** → **Copy link** → paste it into your Doc. I'll try to open
   it from there. A very big zip may still need splitting into 2–3 zips.
4. Optional, free: the **Google Drive for desktop** app uploads in the background and restarts by itself if the
   internet drops.

| Pros | Cons |
|---|---|
| Free; one file instead of 2,400; works with the Google account you already have | Big zips take a while on slow internet; the free Drive is 15 GB total |
