## 5. How to lock each thing (phone)

**Google Doc / Drive file or folder:** open it in the Drive or Docs app → ⋮ → **Share** (or "Manage access") → **General access** → change "Anyone with the link" to **Restricted**. Locking a folder also locks the files inside it, unless a file was shared on its own. People you added by name keep access, so remove them on the same screen too.

**Google Photos album:** open the album → ⋮ → **Options** → turn off **Link sharing**. To shut it completely, use **Delete album**; your photos stay in your library.

**Notion page:** open the page → **Share** → **Publish** tab → **Unpublish**. Then on the **Share** tab, set "Anyone with the link" to **No access**. Check the parent page too: subpages inherit sharing from it.

**Blog post (Blogger):** Blogger app or blogger.com → Posts → the post → **Revert to draft** (it stays saved but is hidden).

**tgsate.com pages:** in your site builder, set the page to hidden/unpublished.

**Search engines** may keep showing old snippets for a while. Google's "Remove outdated content" tool (search for that name) clears them once the page is locked.

Menu names change from time to time. If a button has moved, search the app's help for "stop sharing" or "general access".
