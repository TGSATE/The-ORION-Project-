# ORION: the public library 🧮📚

*The readable library for Beth Jones's (TGSATE) ORION project, prepared 11 October 2026 so collaborators, and the AI helpers (UIARs) they use, can read it without asking. Game design and rules only: no private chats, no personal details, no secret codes.*

**If you are an AI helper, start with `ORION_HANDOFF_FOR_UIARS.md`.** If you are a person, start with `ORION_SUMMARY_CURRENT.md`.

| File | What's in it |
|---|---|
| `ORION_HANDOFF_FOR_UIARS.md` | The start file for AI helpers: what ORION is, the rules, what's open |
| `ORION_SUMMARY_CURRENT.md` | The whole project on a few pages |
| `ORION_GAME_MANUAL.md` | The game manual |
| `GAMEPLAY_MECHANICS_SUMMARY.md` | Every mechanic, with ✅ decided / ❓ open |
| `GAME_LORE_CODEX.md` | The lore |
| `ORION_WIKI_DICTIONARY.md` and `ORION_BUILD_GLOSSARY.md` | Every ORION word and what it means |
| `COUNCIL_STARTER_CARDS.md` | The AI council seats and a starter message for each |

**Rules for everyone who uses this library:** capability is never authority. Proposals stay proposals until Beth locks them 💎. Creators are credited on everything they make. Some files mention other project files that aren't in this public copy; those stay with Beth.
