# How to Navigate the Cosmos 🌌🧭 (the HUD / HHttG)

*Started in Round 16, 7 October 2026, from Beth's note: "we need to go ahead and start constructing a 'how to navigate the cosmos' instructional … a state of the game, a game summary, tutorials for everything … game development, processes and production planning, etc. because I have no idea what I'm doing. If you could get us a good outline of what we have versus what we need and some type of a production plan."*

Beth labelled the link to this round's doc **"HUD/HHttG"**. I've read that as the **HUD** (heads-up display: the always-on overlay that tells a player where they are) and the **HHttG**, a *Hitchhiker's Guide to the Galaxy*-style handbook. So this folder is both: the HUD shows the project's state at a glance, and the Guide explains how to get around. If HHttG meant something else, tell me and I'll rename it.

**This is the front door for the whole team,** not just Beth. Anyone joining ORION (developer, artist, educator, AI) should be able to start here and find their way without reading 16 rounds of history.

## Ground rules this guide follows

1. **Design is not a build.** Anything described here as a rule is a *design* rule unless the guide says it runs in software. Today, **there is no playable ORION build and no live ORION site** (see 01).
2. **💎 means Beth locked it. 🌀/"proposal" means it isn't locked.** The ID numbers (C-06, M-5, O-3 and so on) point into `CONTRADICTIONS_REGISTER.md`; a few (E-2, F-4) are question numbers from the Round 12 and 13 readouts.
3. **"Proved" means proved about a written model in Lean**, not about the world and not about code that doesn't exist yet.
4. **Safety first:** child safety, privacy and consent come before features. When in doubt, a tutorial says to stop and ask a responsible adult or an expert.
5. **Not legal, medical or financial advice.** Where those come up, the guide says who to ask.

## Keeping it current

Each round, the readout says what changed. When something changes the state of the game, `01_STATE_OF_THE_GAME.md` gets a dated line. When a tutorial's steps change (apps change their menus often), fix the tutorial and note the date at the top.
