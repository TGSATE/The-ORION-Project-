# Voynich Manuscript — split note

The original file `Voynich_Manuscript.pdf` (56 MB, 209 pages) is too large for
GitHub's web upload, which caps files at 25 MB. It has been split into four
parts, each under 15 MB, in page order:

- `Voynich_Manuscript_part1of4.pdf` — pages 1–53
- `Voynich_Manuscript_part2of4.pdf` — pages 54–105
- `Voynich_Manuscript_part3of4.pdf` — pages 106–157
- `Voynich_Manuscript_part4of4.pdf` — pages 158–209

Together the four parts contain all 209 pages of the original, nothing
removed. The unsplit original is preserved in the Aristotle project
(ORIONS GATE) and in the downloaded archive.
