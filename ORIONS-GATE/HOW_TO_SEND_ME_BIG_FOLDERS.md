## Three ways to get your stuff to me, easiest first

### 1. Send a Google Drive link (no uploading)
This has worked before: I read your three Drive folders in Round 15.
1. In Google Drive, right-click the folder → **Share** → **General access** → **Anyone with the link** (Viewer).
2. Paste that link into your next message to me.
3. ⚠️ Anyone who has the link can see what's in that folder. Leave personal items out (for example, the birth-chart doc). When I'm done, switch it back to **Restricted**.

### 2. Zip it, then attach the zip file
A single zip file is much easier to attach than a folder full of files.
- **Mac:** right-click the folder → **Compress "Folder name"**.
- **Windows:** right-click the folder → **Send to → Compressed (zipped) folder**.

If the zip is very large, split it into a few smaller zips, such as one per round or one per topic.

### 3. Start a new project from the homepage with the folder
If you do this, tell me in the first message that it continues the Orion project, so the work joins up.

## Rules of thumb
- You don't have to send everything at once. Send one folder, then the next. 🐢
- Text files and Google Docs are easiest for me to read. I can't watch videos, and I may not be able to open photos or audio.
- Nothing gets lost if you take a break.
