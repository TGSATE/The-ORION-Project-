## 2. Who can see whom, and who can talk to whom

| From → To | Under-13 | 13–17 | Adult |
|---|---|---|---|
| **Under-13** | only with a verified guardian of *that* child present (💎) | only with that child's guardian present (💎) | only its own guardian alone; anyone else only with the guardian present (💎) |
| **13–17** | guardian of the under-13 must be present (💎) | **GAP**: "less strict", not yet written | no one-to-one (💎); only in public, guardian-visible ways |
| **Verified guardian** | own child: yes, alone | own child: yes, alone | normal adult rules |
| **Verified educator** | classrooms, public boards, tiered-access boards; contact goes through the parent portal; **never private** (💎) | same (💎) | normal |
| **Admin / monitor** | watches every restricted area; can step in to redirect (🌀) | same (🌀) | normal |
| **Any other adult** | **never** alone (💎); only in a bubble where the guardian is present, or in a bubble group chat everyone attached can read | same (💎) | normal |

**Hard rules (💎):**
1. If you're the only adult in a conversation, you can't invite a child in, and the child can't join you.
2. If the parent isn't in the room, the full transcript goes to them afterwards. There is **no** moment-by-moment biometric replay; you ruled that is "too much".
3. With no parent available, the most anyone else can do is message the child on a public board the parent belongs to.
4. **When a guardian leaves, the child stays.** The child stays in a sealed, one-person room that nobody else can join (💎, corrected R10 late). The child is never thrown out.
