# The ORION Engine — Global Project

ORION is a layered global environment for learning, creativity, community, governance, and interactive development. It is not only an MMO, an educational website, or a social platform. At its center is the ORION Engine, the umbrella system that coordinates the project's platforms — the Singularity, Elder's Garden, the Playground, the Orion Chronicles (the MMO), the Ascent, ORION's Gate, and UIAR — while keeping the human in control: capability should never automatically become authority.

## Start here

- **Overview (the blueprint)** — [The ORION Global Project](https://docs.google.com/document/d/19cFN0GWDluHeuWi2GcwVxXgaDbmfVyfCMcSSzt2vEnA/edit?usp=drivesdk): architecture, platforms, and the Call to Builders.
- **Call to Builders** — in the overview, under "Call to Builders: The Ground Floor of the ORION Ecosystem." This is a founder-credit build; there is no salary today.
- **First milestone** — bring the front door online: the landing page, sign-up and login, a Singularity room once you're logged in, then the Playground. No code exists yet; nothing to inherit.
- **Live working piece** — [Ghostwriter in the Mirror](https://ghostwriter-mirror.abethjones.workers.dev/): the writing mirror, a small working proof of the mirror idea. Separate from the Engine.

## The archive

This repository holds the contents of the **ORION ROOT REPO** Google Drive folder,
the working archive of the TGS:ATE / ORION build group, preserved here so
collaborators can access it and run with their builds.

## Layout

The folder structure mirrors the Drive folder as it stood on 2026-10-30:

- `ORION Platform Project Files/` — platform project files, councils, manuscripts
- `TGSATE/` — publication and outreach materials, webpage sources
- `Processing/` — in-process materials

`ORIONS-GATE/` is a separate top-level area: the ORIONS GATE project, published from the Aristotle app (1,504 files; the Voynich manuscript is split into four parts because of GitHub's file-size limit).

## What is not here, and why

- **One movie file** (`Ender's Game 2013`, 817 MB) was left out: it exceeds
  GitHub's 100 MB file limit, and it is a copyrighted film.
- **Google-native files** (Docs, Slides, Sites) cannot be stored as files.
  They are listed in `NATIVE_FILES_INDEX.md` with their Drive locations;
  the originals still live in the ORION ROOT REPO Drive folder.
- The Google Site itself (tgsate.com) is not a file and is not included.
