# ORION ROOT REPO — Archive

This repository holds the contents of the **ORION ROOT REPO** Google Drive folder,
the working archive of the TGS:ATE / ORION build group, preserved here so
collaborators can access it and run with their builds.

## Layout

The folder structure mirrors the Drive folder as it stood on 2026-10-30:

- `ORION Platform Project Files/` — platform project files, councils, manuscripts
- `TGSATE/` — publication and outreach materials, webpage sources
- `Processing/` — in-process materials

## What is not here, and why

- **One movie file** (`Ender's Game 2013`, 817 MB) was left out: it exceeds
  GitHub's 100 MB file limit, and it is a copyrighted film.
- **Google-native files** (Docs, Slides, Sites) cannot be stored as files.
  They are listed in `NATIVE_FILES_INDEX.md` with their Drive locations;
  the originals still live in the ORION ROOT REPO Drive folder.
- The Google Site itself (tgsate.com) is not a file and is not included.

## For collaborators

Clone the repository and work from the folders above. The TGS:ATE project is
human-led: the human Catalyst holds final accountability. See the project
history in the folders for context.
